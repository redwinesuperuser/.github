## 🤔 Getting Help

### GitHub Discussions

For questions, ideas, and community support:

1. Visit [GitHub Discussions](https://github.com/github/awesome-copilot/discussions)
2. Search existing discussions to see if your question has been answered
3. Create a new discussion if needed

**Discussion Categories**:
- **Q&A**: Ask questions and get help from the community
- **Ideas**: Share ideas for new features or improvements
- **Show and Tell**: Share what you've built with Awesome Copilot
- **General**: General discussions about the project

### GitHub Issues

For bug reports and feature requests:

1. Visit [GitHub Issues](https://github.com/github/awesome-copilot/issues)
2. Search existing issues to avoid duplicates
3. Create a new issue using the appropriate template

**When creating an issue, include**:
- Clear title describing the problem or request
- Steps to reproduce (for bugs)
- Expected vs. actual behavior
- Environment details (OS, editor, Copilot version)
- Relevant code samples or screenshots


## 🚀 Quick Troubleshooting

### Common Issues

#### Agent Not Working

1. Check frontmatter is valid YAML
2. Verify file has correct extension (`.agent.md`)
3. Ensure agent is in the correct directory
4. Reload your editor
5. Check GitHub Copilot is enabled and working

#### Prompt Not Appearing

1. Verify file has `.prompt.md` extension
2. Check frontmatter is complete
3. Ensure file is in `/prompts/` directory
4. Restart GitHub Copilot extension

#### Instructions Not Applying

1. Verify `filePattern` matches your files
2. Check file has `.instructions.md` extension
3. Ensure frontmatter is valid
4. Reload workspace

#### Plugin Installation Failed

1. Verify plugin structure is correct
2. Check all referenced files exist
3. Ensure `README.md` is present
4. Review plugin documentation

### Installation Issues

#### MCP Server Not Starting

1. Ensure Docker is installed and running
2. Check Docker image is available
3. Verify MCP configuration is correct
4. Check logs for error messages

#### Customizations Not Loading

1. Verify installation path is correct
2. Check file permissions
3. Restart your editor
4. Clear editor cache if available

## 📝 What We Can Help With

✅ **We can help with**:
- How to use agents, prompts, instructions, and skills
- Creating and contributing new content
- Understanding the repository structure
- Troubleshooting issues with this repository
- Feature requests and improvements

❌ **We cannot help with**:
- General GitHub Copilot issues (contact GitHub Support)
- Third-party service issues
- Custom code debugging (unless related to our content)
- Enterprise-specific GitHub issues
